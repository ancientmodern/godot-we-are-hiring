# 《我们正在招人》

[English](README.md)

《我们正在招人》是一款使用 Godot 4 制作的单机经营叙事游戏。你将经营一家位于湾区的 AI 创业公司，在现金、算力、融资与招聘之间作出选择，并不断面对一个越来越诱人的问题：要不要把工作交给日益强大的内部模型？

它会让每一周都变得轻松，也可能逐渐成为这家公司的真正作者。

## 游戏特色

- 三种出身与各自的序章：你为什么会走到那扇车库门前
- 五章、45 个经营周的完整战役
- 融资、招聘、股权、办公室与 SaaS 等相互影响的经营系统
- 固定与动态叙事事件，以及多条分支结局
- 离开经营面板、可直接探索的夜班场景
- 自动存档与新周目开场
- 完整支持鼠标、键盘与手柄
- 原创中文文本与美术

## 运行方式

推荐使用 Godot 4.7，兼容的 Godot 4.x 桌面版本也可能正常运行。

1. 安装 Git LFS 并克隆仓库：

   ```bash
   git lfs install
   git clone git@github.com:ancientmodern/godot-we-are-hiring.git
   cd godot-we-are-hiring
   git lfs pull
   ```

2. 在 Godot 项目管理器中导入 `project.godot`。
3. 按 **F5** 运行主场景。

Windows 用户也可以运行 `run_game.bat`；脚本会依次检查 `GODOT_EXE`、常见 Steam 路径和系统 `PATH`。

## 基本操作

- **鼠标：** 选择与交互
- **键盘：** 方向键或 `W`/`S` 导航，`Enter`/`Space` 确认，`E` 推进
- **快捷键：** `T` 团队、`C` 日历、`A` 公告、`I` 内网、`` ` `` 终端
- **手柄：** D-pad 导航、`A` 确认、`B` 返回
- **设置：** `F1` 或手柄 `Start`；`F11` 切换全屏
