# 《我们正在招人》美术方向：Blue-Hour Ledger 2.0 / 雨印档案

## 北极星

**Blue-Hour Ledger 2.0（雨印档案）**：一册浸在冷雨、窗光与咖啡痕里的湾区公司档案——安静、可信、精确，直到它开始比创始人更像这家公司本身。冷色不是“科技蓝”装饰；档案纸、封套、夹子、台灯和人的使用痕迹共同承担界面，机器只在剧情中真实存在的地方露出玻璃表面。

这是可触摸的独立游戏界面，不是可爱养成、赛博朋克仪表盘、恐怖游戏，也不是通用 SaaS 样机。“贵”来自独特构图、材料一致性、精准层级、具体环境与安静动效，而不是卡片数量、高光或特效堆叠。

## 构图与空间

- 以 **1280×720 / 16:9** 为最低构图基准；其他分辨率延展空白，不拉伸内容。
- 经营页遵循“深色档案封套 + 中央主纸 + 右侧夹纸”；叙事页遵循“58%–68% 全幅场景 + 一张暖人纸”；机器页才使用深色玻璃与精确网格。
- 每个状态只设一个主焦点；留白是质感的一部分，不用额外卡片填满。
- 环境与物件始终主导，UI 像世界内真实存在的档案、批注、热敏纸或机器屏。禁止用 50% 以上的灰白蒙版把场景洗成壁纸；人物事件不得显示经营指标。
- 场景必须给文字和控件预留干净负空间；图像不烘焙可读文字或最终 UI。

## 插画与人物

- 质感是编辑性水粉/墨线，带少量丝网印刷颗粒；边缘稳定，细节在 720p 下仍可辨。
- 场景用具体的湾区初创物件说话：雨夜玻璃、白板、连帽衫、桌面电缆、空椅子、餐盒、灯下文档。避免照片素材拼贴和无特征“办公室风”。
- 同一地点的日/夜版共享几何、机位和物件；只改光线、使用痕迹和屏幕状态。
- 不采用 chibi/Q 版、动漫魅化、赛博霓虹、写实库存摄影或恐怖语法。

### 创始人：不可识别

创始人始终不命名、无脸、无独立肖像。不展示嘴、眼睛、完整头部或可识别倒影；可用手、下巴以下的裁切肩身、鼠标、空椅、影子和无身份屏幕反光表达存在。

需要表现“嘴型对上了”等直播观察时，证据使用手势、字幕、声纹、进度/暂停和旁观者反应，不能为证明剧情而破坏无脸规则。

### 林越：人的锚点

`lin_yue_portrait_v2.png` 是可反复出现的核心人物肖像锚点，用于林越亲自介入的剧情节点、团队记录或人物资料；不作常驻导航吉祥物。它使用与场景一致的水粉、墨线和深板岩纸面，不再使用商业宣传式轮廓光。保持专业、克制、可信的联合创始人气质，不做恋爱游戏/gacha 式裁切、连续对嘴或夸张表情。不为无脸创始人制作对称肖像。

## 表面与交互物件

- 只允许三种表面：冷档案纸、暖人纸、深色机器玻璃。每屏最多一个主表面和一个证据窗口，禁止卡片套卡片。
- 文档圆角 0–3px，控件 3–4px；只有 Pause/辅助设置可使用 8px。整叠纸只有一个投影，列表行只用规则线、冲孔或 3px 装订线。
- 选中行右移 6–8px并出现海玻璃装订线；按钮表现为签批条、索引签或印章，不使用 Web 胶囊与大面积 hover 光。
- 稳定几何比装饰重要；数字更新、状态切换时不跳动重排。
- **夜班是被批注的照片，不是平面图。** 物件的热点画在它在画面里真正所在的位置：四角检查框、一条细引线、一块贴边说明。不铺盖住画的深色面板，不画网格线，不把大图缩成读不出内容的缩略图——它们在那个尺寸上不再是画。玩家的位置由感应灯的光斑表达，没有化身圆点。
- 异常内容使用普通组件、普通文案层级和普通动画；禁止专用光晕、弹窗、音效刺点或“这里有秘密”的提示。

## 字体与层级

系统与经营数据使用 `assets/fonts/NotoSansSC-Variable.ttf`；事件标题、人的文档与结局使用 `assets/fonts/NotoSerifSC-Variable.ttf`。两款字体均随附 OFL 1.1 授权。中文优先，英文只保留一条 imprint；仅终端/时间码使用等宽语境。

七级阶梯，之间没有中间值。运行时定义见 [`docs/ui_design_system.md`](ui_design_system.md) 第 3 节。

| 层级 | 720p 字号 | 规则 |
| --- | --- | --- |
| Hero | 46 | 只用于开场或结局第一页 |
| Display | 32 | 单个屏幕不超过一个 |
| Section | 22 | 分区标题与所有大号数字（衬线） |
| Action | 17 | 按钮与行动名 |
| Body | 16 | 正文与列表项 |
| Label | 14 | 字段名与表头 |
| Meta | 12 | 元数据、快捷键和页码 |

720p 下不使用小于 12px 的可交互或必读文字；绘制入口本身取下限，所以更小的数字只会静默变成 12，而不会变小——写 token，不写字号。手写仅限白板草图等场景内道具，不用作 UI 字体。

## 动效语法

- 面板切换 **160–220ms**；数字/进度缓动 **280–420ms**；重要状态改变 **500–700ms**；环境循环 **4–10s**。
- 优先表现输入、状态转移和人的犹豫：光标停顿、椅子轻移、屏幕刷新、手势、声纹、社交心形的延迟出现。
- 禁止无处不在的弹跳、摇摆、镜头震动和成功礼花。异常使用与日常相同的 easing 和时长。
- 所有纯装饰动画需可在减少动效模式中关闭；验收/截图模式必须可确定地固定帧。

## 灵感来源与不复制红线

研究参考仅来自《中国式家长》的[Steam 官方商店页](https://store.steampowered.com/app/736190/Chinese_Parents/?l=schinese)、[Nintendo 官方商店页](https://www.nintendo.com/en-ca/store/products/chinese-parents-switch/)、[Steam 官方版本迁移说明](https://store.steampowered.com/news/app/736190/view/4168722301033426396) 和[Steam 官方宠物系统公告](https://steamcommunity.com/ogg/736190/announcements/detail/4452466204163964998)。我们只借鉴高层原则：稳定管理框架与人性化场景并置、可触的插画纹理、清晰的行动分组、人物与环境的结合，以及 UI 优先的动画。

**没有任何参考作品的图像、截图、裁切、纹理、图标、字体、文案、对白、音乐或动画进入本项目或发行包。** 官方素材跨越不同版本，本项目也不尝试还原其中任何一版。

禁止：

- 临摹、描图、覆画、抽取纹理，或使用“仿某作品风格”的生成指令。
- 复制标题/商标、角色轮廓、家庭/教室环境、精确页面比例或暖羊皮纸+绿色按钮配色。
- 复制脑区/碎片隐喻、满意度/压力条、面孔对决、红包、世代树或其他可识别的视觉系统。
- 复制文案、笑话、对白、图标集、转场节奏、音效或音乐。

## 候选美术验收

- [x] 创始人无脸、无名、无肖像，包括反射和裁切边缘。
- [x] 林越肖像只在有叙事理由时出现，没有吉祥物化或恋爱游戏化。
- [x] 720p 下文字、焦点、状态和操作均可辨；全局文字绘制入口强制不小于 12px，交互目标不小于 44×44，并由 87 屏回归覆盖。
- [x] 只使用已定义的色彩角色；错误/后果、警告、成功与信息提示分开，普通资源门槛不借用后果红。
- [x] 场景图没有烘焙文字/UI，裁切后仍有足够的负空间。
- [x] 异常没有专属配色、强调效果、动画或音效。
- [x] 降低动态模式可用并持久化；关闭滑入、脉冲、长等待和循环装饰，同时保留状态反馈。
- [x] 可确定截图路径可用；根截图目录由 87 个显式 stem 清单约束，非清单 PNG 归档且会使像素契约失败。
- [x] 依赖闭包与候选清单证明候选包不含参考源艺术或旧演示资产。
- [ ] 用户在可见运行中完成最终主观美术验收；该项不影响自动化实现证据，但决定是否继续下一轮风格微调。
