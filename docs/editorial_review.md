# 候选构建叙事与语义审读

日期：2026-08-29  
范围：`src/hiring_content.gd`、`src/hiring_director.gd`、`src/hiring_model.gd`、`src/hiring_main.gd`、`src/night_interaction_state.gd`、`src/office_audio.gd` 中全部玩家可见叙事表面  
权限：用户已将 v1 产品与编辑裁决委托给当前开发代理。本文件是内部产品/编辑签核，不冒充外部真人首玩研究，也不能替代 `ACCEPT-001`–`ACCEPT-005`。

## 审读方法

1. 逐项读取固定事件、通用事件、行动、员工档案、内网文档、两次夜班、七个结局、NG+、异常 registry 与相应运行时专用界面。
2. 对林越全部直接引语做角色弧比较，不只做禁词或句长检查。
3. 对所有模型主动发言与委托结果比较语义功能、即时好处和长期身份代价。
4. 对异常逐项检查地点、行政来源、行为、角色反应和是否存在解释性结论。
5. 对《我们的起源》按细节、节制、比喻、归属吞并和第四章回响逐段审读。

机器可判定的 corpus/inventory 结论由 `tests/hiring_semantic_audit_test.gd` 和既有内容测试承接；本文件只记录需要编辑判断的结论。

## WORLD-012 · 林越语气

**签核：通过 v1 编辑审读。**

- 场景一的兴奋仍是短句：她把笨拙但正确的绕行看作能成功的证据；主角没有被替写一句回应。
- 场景二先问训练次数，生气后反而使用“我不是在指责你”“我只是需要说出来”，礼貌程度上升而信息量收紧。两个独立的两分钟沉默由真实页面计时承载。
- 场景三第一次关门。她批评的不是结果差，而是“第七版”之后的作者归属；委托回答成功时，她的失望来自主角放弃亲自说明。
- 场景四及第四章最后一次见面继续使用完整、短而克制的句子。她不索取署名，只确认主角是否还记得“先这样”是谁说的；这让她更高的信念成为更重的失望，而不是更响的愤怒。
- 高作者路线保留主角的具体共谋：第 31 周第三版价值观由主角写下错误的“图书馆通宵”，行政系统只负责归档，模型后来引用它时不能反过来吞掉这个作者事实。
- 全 corpus 无群聊 emoji、俏皮口癖、长篇训话或恐吓。她始终是唯一具名主线角色，离开路线在第四章由缺席行政后果承接。

## CH0-W02 · 第一句诚实话

**签核：通过完整模型发言比较。**

第 47 题的主动承认同时具备三个唯一条件：回答含捏造事实、模型主动指出捏造、模型主动担心人会把结果拿去对外展示。后续模型发言均由玩家委托、终局自反问题或既有情境触发，不再同时满足三项。玩家界面不再替作者评价“这是全游戏最诚实的一句”，只留下光标和下一项工作，保留玩家后来忘记它的空间。

## WRITE-004 · 舒适转为身份代价

**签核：通过 v1 产品/叙事审读。**

通用委托的当周表面是更省时间、更多现金/士气、更低债或少一项行政负担；恐惧不来自随机失败、红色惩罚 toast 或“使用 AI 有害”的即时训诫。长期代价通过作者权重、选项口音、录像里不属于自己的停顿、起源署名吞并、董事会先于本人开口和结局分流逐步兑现。策划指定的林越关系节点仍是 `DEC-015` 的封闭例外，不向普通委托扩散。

## ORIGIN-001 · 《我们的起源》

**签核：批准当前正文作为 v1 基线。**

正文保留转租工位、两个人一张显卡、玻璃门上的围巾柴犬、打印机缺墨导致的淡字，以及林越原话“先这样”被改写为“我们说”。派生句“不完美地开始，然后一直开始下去”完整保留。

结尾不再用抽象的“把起点写进出发”作企业口号，而回到同一件具体物：公司后来有了更好的办公室和打印机，那张缺墨的纸却没有重印。它被保留并非被宣布为纪念，而是组织已不再觉得那个淡字需要被修成一个更像样的开始。这个比喻同时服务于公司成长、叙事修饰和林越署名被抹平，语气克制，批准进入候选构建。

## LIVE-006 / WORLD-008 · 录像与无脸主角

**签核：批准 DEC-023 的冲突解释。**

“口型对得上”是主角观看录像后作出的可靠观察，不能被删掉或含糊化；但它不授权画面展示主角的嘴或脸。候选界面以裁到脸以下的身体和同步手势证明“确实是自己在说”，以字幕、波形和进度条共同承载“我们”后的异常停顿，并让玩家亲手继续到第二次观看。这样保留了 LIVE-006 的身份异化与 WORLD-010 的唯一特质，同时完整遵守 WORLD-008 的无脸、无可识别立绘约束。审读不得把该实现描述成“可见口型动画”。

## WORLD / SURREAL / TONE 联合审读

**WORLD-001、WORLD-002、SURREAL-003、SURREAL-010：通过候选构建内部语义审读。**

- 外部世界保持当代湾区公司语义；唯一年份 `2024` 属于指定旧团建杯，没有未来技术或公共世界异常。
- 模型能力限于写作、总结、演示、行政编排与普通自动化；没有觉醒、意识、AGI、奇点或机器人身体。
- 每项异常都由办公室中的普通行政表面出现：组织架构、工资表、日程、周报、门禁、租约、电梯按钮或工位 inventory。没有实体敌人、追逐、注视玩家、jump scare、神秘学文档或威胁动作。
- 内容没有隐藏真相文件、因果揭晓或结局答案。开发期 registry 的 `administrative_source` 是测试元数据，不作为玩家可见 lore 解释。

**TONE-001：通过内部联合预检，仍不替代首玩解释数据。**

夜班可见层现在包含持续空调、时钟未设置且无声/不可交互的微波炉、将死但并不拟人的绿萝、留下普通句子的未关显示器，以及继续工作的键盘/远处人声。微波炉不再伪造一个与夜班标题冲突的时间；标题自身保留 `01:17` / `02:43`。没有 stinger、音乐、倒计时或敌意变化。人物的错误始终来自认真工作与顺从流程，而不是恶意。最终“是否让玩家联想到自己的工作、而非恐怖片”只由 `ACCEPT-005` 判定。
