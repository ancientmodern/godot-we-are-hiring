# Blue-Hour Ledger / 蓝夜档案设计系统

版本：2.0 / 雨印档案  
适用范围：所有 1280×720 游戏界面、叙事窗口、夜班物件、设置、反馈与后续美术资产。

## 1. 母题

游戏把创业公司的档案、桌面与机器当成叙事现场：白天是可触的经营卷宗，人物戏是未经洗白的真实场景，夜里是仍然遵守同一套秩序的空办公室。仅借鉴参考作品“生活材料与管理循环并置”的高层原则，不复刻其人物、构图、图标或界面；本项目使用冷雨蓝绿、纸纤维、金属夹与更克制的湾区公司物件。

三个关键词：`克制`、`可读`、`有余温`。

- 系统表面永远偏冷；真实的人留下的纸张、杯子、围巾和手写痕迹才允许偏暖。
- 异常不换一套“恐怖 UI”。它仍使用普通按钮、日历和组织架构，只让内容与状态产生偏差。
- 高级感来自一致的比例、留白、层级和反馈，不来自高光、粒子、震屏或装饰堆叠。

| Token | 色值 | 唯一含义 |
|---|---:|---|
| Mist | `#DDE5E8` | 全局冷雾背景 |
| Porcelain | `#F6F7F3` | 普通卡片与控件 |
| Deep Teal | `#102028` | 主操作、侧栏、系统深色面 |
| Ink | `#18262D` | 主要文字 |
| Muted | `#52666F` | 次要信息 |
| Line | `#B7C5CA` | 普通边线 |
| Sea Glass | `#2F746C` | 可执行、已确认 |
| Focus Mint | `#55AFA1` | hover、键盘/手柄焦点 |
| Info | `#3F7186` | 中性系统通知 |
| Human | `#9A5C26` | 人的痕迹、待处理事项 |
| Consequence | `#A94F52` | 不可逆后果、失败 |

禁止在公共组件里加入散装颜色。绿色不表示“漂亮”，只表示可执行或完成；琥珀不表示普通强调，只表示人的痕迹或待确认；红色只用于不可逆后果与失败。

## 3. 字体与排版

双字体系统：`Noto Sans SC Variable` 500 用于系统、数据与操作；`Noto Serif SC Variable` 650 用于事件标题、人的文档与结局。

| 级别 | 字号 / 行高 | 用途 |
|---|---:|---|
| Meta | 12 / 16 | 元数据、快捷键、页码 |
| Body | 14 / 22 | 正文、说明 |
| Action | 15 / 20 | 按钮与行动名 |
| Section | 20 / 28 | 页面小标题 |
| Display | 32 / 40 | 页面标题 |
| Hero | 48 / 56 | 极少数章节标题 |

必读或可交互文字不得低于 12px。场景内道具文字也默认遵守 12px；确需更小者必须只承担氛围，不承担信息。数值、页码与资源列使用稳定宽度并右对齐。

## 4. 网格、几何与层级

- 基础网格 8px；允许的间距只有 `4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 经营 folio 使用约 272px 封套索引、440–500px 主纸、330–350px 夹纸；场景页至少 45% 插画不被灰白蒙版覆盖。
- 所有点击区域至少 `44×44`；标准控件高 48px，首屏 CTA 高 56px。
- 文档与列表 `R0–3`，签批控件 `R3–4`，Pause `R8`；胶囊形只用于开关。
- 普通边线 1px，焦点环 2px并向外留 2px。
- 阴影只有两档：`E1 y+2 / #071319@11%` 用于纸张与按钮；`E2 y+7 / @24%` 只用于整叠档案或 Pause。列表行没有独立阴影。

## 5. 公共组件

### LedgerButton

变体只有 `Primary / Secondary / Quiet / Attention / Danger / Night / Disabled`。主标签与快捷键分槽显示，不能再把 `ENTER`、`ESC` 或 `E` 拼进主文案。

状态契约：

- Rest：标准底色与 E1。
- Hover：120ms cubic-out，仅向 Focus Mint 混合 8%，文字不位移。
- Pressed：60ms，下移 1px并收起阴影；释放 100ms。
- Focus：外扩 2px薄荷环，和 selected 左轨不是同一状态。
- Disabled：无 hover、press 或焦点诱导。

### FolioSheet / HumanDocument / MachineGlass / NightInspector

- `FolioSheet` 是一整张冷纸；行动、数据和分页直接画在纸上，不再拆成独立卡片。
- `HumanDocument` 只给真实人物留下的材料使用暖纸色。
- `MachineGlass` 只给 LANTERN、终端、录像、董事会等叙事上真实存在的机器界面。
- `NightInspector` 使用夜间深色面与夜间文字；固定 header/body/footer，有明确的 44px 收起按钮与 `Enter/Esc`，不允许“点击任意处关闭”成为唯一操作。
- 人物剧情不使用中央 modal；Pause 可使用 572px 控制单，夜班 inspector 固定为窄侧页。

### PageStepper

顺序永远为 `上一页 | x / y | 下一页`。前后按钮 `44×44`，间距 8px，计数槽至少 `52×44`。团队、内网、公告栏共用相同构造。文档分页按真实字体宽度与行高计算；章节标题必须和至少一行正文同页。若末页过疏，则把上一完整小节整体前移，让翻页保持编辑感，而不是只留下两行孤零零的正文。公告也在不超过六条/页的前提下均匀分配，避免终页只剩一张孤卡。

### StatusToast

Toast 由 `Info / Success / Warning / Error` 决定左轨和边色，深青底，48px 高，最大宽 480px，距安全边界至少 24px并避让 footer。Info/Success 保留 2.6s，Warning 4.5s，Error 5.2s。失败绝不使用成功绿。

## 6. 动效

| Token | 时长 | 用途 |
|---|---:|---|
| Fast | 120ms | hover、即时反馈 |
| Panel | 180ms | Toast、面板进入 |
| Data | 320ms | 数据与卡片揭示 |
| Story | 600ms | 叙事状态转换 |

全部使用 cubic-out。位移不超过 12px，缩放只允许 `0.98 → 1`。环境循环 6–10s，位移振幅不超过 2px、透明度变化不超过 0.06。禁止弹跳、震屏、强光晕与庆祝粒子。

Reduced Motion 开启后：循环、脉冲、滑入、缩放和模拟移动下一帧直接到终态；叙事等待不超过 150ms；hover/pressed 仍保留静态色差；不会为了“无动画”而丢失状态反馈。

## 7. 美术与世界观一致性

- 原创平面编辑插画：冷蓝灰、海玻璃绿、克制纸纹与少量暖棕；人物不做廉价头像墙。
- 创始人始终无明确正脸。镜头通过手、背影、座位、杯子和屏幕表达存在。
- 大图必须有状态版本：绿萝随债务分级，Room D 的门/距离/灯写入画面，杯子的位置写入画面。
- 小图标使用同一 2px 笔画、8px 几何和色义；不得混入 emoji、系统默认图标或写实库存图。
- “超自然”永远表现为普通系统的精确偏差，不加恐怖滤镜或惊吓特效。

## 8. 声音与触感一致性

- 环境声先说明“玩家现在在哪”：办公室、咖啡馆、会议室、夜班、服务器区不得共用错误 room tone。
- 配乐只有 `human` 与 `system` 两个极稀疏动机，平均低于房间底噪；不替玩家判断成功、失败、恐怖或真相。
- 交互声来自世界内材料：纸张、铅笔、印章、键帽、门锁、脚步、杯子、投影和手机玻璃。禁止通用 Web beep、hover 连响、奖励 arpeggio 与 notification ding。
- 每个可听 one-shot 必须同时满足：玩家直接触发、画面中存在对应物理动作、90ms 内不重复轰炸、全局静音立即停止。
- silent beat、异常、作者阶段变化、自动保存和隐藏数值变化没有 cue；林越沉默页只保留被指定的 room tone。

## 9. 交付检查表

每个新界面在合入前必须回答：

1. 它使用了哪一种既有表面、按钮和反馈组件？
2. 所有必读文字是否至少 12px，所有目标是否至少 44×44？
3. 鼠标、键盘和手柄能否完成同一条路径并看见焦点？
4. hover、pressed、selected、disabled 是否彼此可区分？
5. Reduced Motion 下一帧是否等于正常动画终态？
6. 颜色是否仍保持“系统冷、人迹暖、后果红”的世界规则？
7. 截图清单是否覆盖默认态、第二页、设置态、降低动态态和关键叙事状态？
8. 声音是否来自当前空间/材料，并且没有替静默或异常“打点”？
